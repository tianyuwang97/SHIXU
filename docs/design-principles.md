# 时序 SHIXU｜审美与交互设计要求

整理日期：2026 年 9 月 17 日  
依据：本次对话中可见的文字要求、截图、参考说明及后续修正。

> **一句话概括：有 Web3 的鲜明个性，有纯色色块的立体趣味，有柔顺克制的动效，同时让研究内容和操作入口足够直接。**

## 阅读说明

- **明确要求**：你直接提出、选择或认可的设计方向。
- **归纳原则**：从多次反馈中提炼出的执行标准，不冒充你的原话。
- **以后提出的修正优先**：例如，金币从“要有质感”进一步明确为“不要金属感”；滚动从“果冻感”收敛为“柔顺就可以”。

## 一、整体气质：你究竟想要什么

### 1. 要有设计感，不能只是功能齐全

**明确要求**

- 你反复要求“美学”“质感”，关注字体、比例、留白、位置、动画和交互手感。
- 网站不能只有静态内容：按钮、页面滚动、元素出现，都需要有设计过的反馈。
- 字体要与 Web3 气质一致，不能像普通表单或默认提示文字。
- 研究功能很重要，但界面不能因此变得笨重、杂乱。

**归纳原则**

质感应来自一致的视觉语言、舒服的比例和自然的动态，而不是堆积装饰、反光或不断运动的元素。

### 2. MetaMask 是重要参考，但要转化成时序自己的表达

**明确要求**

- 参考 MetaMask 登录页：简洁的主体、底部露出的角色，以及角色自行出现的动画。
- 参考小狐狸的纯色色块与立体切面，而不是写实金属材质。
- 参考其滚动的柔顺感。

**归纳原则**

借鉴的是“简洁界面里有一个鲜明、会动的视觉主体”，不是照搬 MetaMask 品牌。时序的主体是金币，品牌是「时序 SHIXU」。

## 二、品牌与中英文字体

### 1. 品牌名称与标语

| 项目 | 当前明确方向 |
| --- | --- |
| 中文名称 | 时序 |
| 英文标识 | SHIXU（当前界面采用） |
| 中文标语 | **度时间，探秩序。** |
| 英文标语 | **Measure Time. Explore Order.**（随中文修正同步更新） |
| 品牌位置 | 主界面左上角，纳入顶部品牌导航区域 |
| 语言关系 | 中英双语都要认真排版，形成整体 |

**取舍记录**

- 最初提出「度时间，知秩序」。
- 后来明确否定“知秩序”，改用“探”。后续设计以「探秩序」为准。

### 2. 字体必须统一

**明确要求**

> “字体太不 web3 了，统一风格。”

- 品牌、导航、按钮、输入框、访客入口、登录报错，都要属于同一套视觉系统。
- 报错和辅助文字不是可以忽略的边角：截图中“账号或密码不正确”“先以访客进入”的观感也需要打磨。
- 不要让局部回到浏览器默认链接、普通细字表单的感觉。

**归纳原则**

- 字形干净、利落；标题与主要操作有明确字重。
- 中英文要协调，不能只设计中文、把英文随意附在下面。
- 字号、字重、字距形成层级，避免所有内容同样醒目。
- Web3 气质不等于必须用难读的科幻字体；信息仍要易读。

**尚未被你指定的内容**

具体字体家族、字重数值、字距数值和色号都属于实现选择，不是已经锁定的个人要求。

## 三、顶部悬浮导航与研究工具

### 1. 选择「悬浮导航岛」

**明确要求**

- 你要求制作三个不同顶部 Demo 以便对比。
- 对比后明确选择“悬浮岛”。
- 顶部这一整块需要整体打磨，不是只换一个 Logo。
- 最近进一步要求：**悬浮栏要更长**。
- 整条悬浮栏相对屏幕居中，左右留白相等，不能被侧边研究栏挤偏。

**归纳原则**

保留独立悬浮的形态，但横向舒展，避免内容区很宽、导航岛却显得局促。左右留白应有统一依据，内部品牌与操作区也应跟随宽度合理分布。

### 2. 滚动时，只有顶部主导航持续留在顶部

**明确要求**

> “下面的这四个按钮不要跟着顶部悬浮栏一起移动，下滑的时候只有顶部悬浮栏一直保持在顶部就好。”

- A 股、美股、港股、基金四个市场按钮留在正常页面内容中。
- 不要让主导航和市场选择一起堆成很厚的吸顶区域。

### 3. 研究工具转到侧边

**明确要求**

- 你认可过用于 Demo 对比的底部工具栏，随后希望把类似工具加入正式版。
- 当时要求上下悬浮栏长度一致。
- 后来又认为研究栏不够美观，提出放到侧边。

**最终优先关系**

- 研究工具以侧边布局这一较新的方向为准。
- “上下同宽”适用于仍然存在上下横向栏的布局，不能据此把已经转到侧边的工具重新放回底部。
- 最新的“悬浮栏更长”针对截图中的顶部导航岛。

### 4. 去掉泛滥的小箭头

**明确要求**

> “不知道为什么那么多按钮都有一个小箭头，能去掉吗。”

- 去掉按钮上重复出现的装饰性右上箭头。
- 不要为了显得有设计感，给每个操作都添加相同符号。

**归纳原则**

真正承担展开、返回等含义的图标应按功能判断；这条要求不是删除所有有作用的方向提示。

## 四、首页的比例、顺序与信息层级

### 1. 重要内容要尽早出现

**明确要求**

- 你认为重要功能放在主页下方不好，要求改善首页入口布局。
- 首页要第一眼就能看到主要指数。
- 登录成功后必须进入页面顶端，不能一进来就停在中间的筛选区域。

**归纳原则**

首屏应让人知道市场情况，并能直接开始研究；装饰不能把这些内容挤得很远。

### 2. 市场排序与名称

- 基金放到最后。
- 当前顺序：**A 股 → 美股 → 港股 → 基金**。
- A 股英文按最新要求简化为 **CHINA**，不再使用 CHINA A-SHARES。
- 英文名称也属于需要打磨的界面内容，不能机械翻译后就结束。

### 3. 首页指数概览

**明确要求的六项内容**

1. 上证指数
2. 科创 50
3. 恒生指数
4. 恒生科技指数
5. 纳斯达克 100
6. 标普 500（你明确把最初的“标普 100”修正为 500）

**视觉反馈**

- 你质疑过为什么前两个指数卡片有额外的框。
- 这说明没有清晰理由的差异化强调会显得奇怪。

**归纳原则**

同一级信息先保持一致。要高亮某些卡片，必须让用户看得懂高亮的含义，而不是只留下视觉差异。

### 4. 删除已经否定的首页文案

你明确要求去掉：

- 「今天，进入哪个市场？」
- 「选择市场，开始你的研究。」

后来觉得只剩金币有点突兀，又要求加一点内容，但明确不能把这两句话放回去。

**执行边界**

可以补充轻量的视觉陪衬，但不能用被否定的大标题重新填空，也不能回到大段介绍占满首屏的状态。

### 5. 留白与大小要靠整体看

**明确要求**

- 金币曾经太大，需要缩小。
- 金币区域上下空白不一致，需要调整。
- 正式版的比例不好时，应参照已经认可的 Demo。

**归纳原则**

让主体视觉居中、上下空间平衡。不要只在 CSS 数值上居中，却让可见图像、阴影、装饰和相邻模块看起来偏移。

## 五、金币：时序的核心视觉角色

### 1. 质感的最终定义

你最初提出“很有质感的金币”，随后明确修正：

> “不要这种金属感，我想要那个小狐狸那样的，比较纯色色块的金币。”

**明确要求**

- 纯色色块。
- 有立体厚度和切面。
- 卡通化、图形化。
- 不走写实金属反射的方向。

**归纳原则**

金币的立体感来自轮廓、厚度和明暗色块之间的关系，而不是强烈高光、金属纹理或镜面效果。

### 2. 首页摆放

**明确要求**

- 首页金币居中，按已认可 Demo 的比例处理。
- 不采用标题在左、金币偏右的那版组合。
- 删除“重播金币出场”按钮。
- 删除金币下面的说明文字。
- 缩小过大的金币。
- 金币单独出现略显突兀，需要少量陪衬。
- 调整上下空白，让整个区域平衡。

**归纳原则**

装饰是配角。不能为了衬托金币，又增加一堆文字、按钮和抢眼元素。

### 3. 不同市场对应不同币面

| 市场 | 你指定的正面图案 |
| --- | --- |
| A 股 | 浦东建筑群 |
| 美股 | 卡通自由女神像 |
| 港股 | 香港维多利亚港 |
| 基金 | 北京中轴线 |

图案要延续同一套纯色色块、立体切面的金币风格，不能四个市场各画各的。

### 4. 市场切换动画是明确认可的亮点

> “金币轻轻转动一下，再露出新图案……这个想法绝了。”

**执行要求**

- 用户选择市场后，金币先轻轻转动，再露出对应的新图案。
- 不要硬切图片。
- 不要变成夸张、长时间的旋转表演。
- 切换动作与市场选择之间的关系应清楚、直接。

### 5. 入口动画与场景要区分

- 最初讨论过金币从侧面弹出。
- 登录页后来有独立、明确的要求：**从下方上来，只露半个**。
- 不应把首页和登录页做成完全相同的摆放方式；它们共享造型风格，但出场方式和构图不同。

## 六、动画：柔顺、有弹性，但不要浮夸

### 1. 不只是给滚轮加效果

你曾明确指出：

> “或许不是滚轮的动画吧……下面的小狐狸耳朵是自己弹出来的。”

**明确要求**

- 页面里需要有自主出场的视觉元素。
- 不能只用滚动字幕、一般位移或页面滚动效果代替角色出场。
- 动效应与具体元素和交互有关。

### 2. 滚动手感的最终标准

需求演变：

1. MetaMask 的滚动“更丝滑、更有果冻感”。
2. 随后收敛为：**“柔顺就可以。”**

**归纳原则**

- 轻缓跟随、自然收尾。
- 不追求强烈拉扯、明显形变或持续弹跳。
- 用户停手后，画面不应长时间漂移。
- 不能为了动效牺牲定位、阅读和操作的可控性。

### 3. 所有内部滚动窗口都要一致

**明确要求**

> “现在这种打开之后的股票列表滑动感觉还不是柔顺，检查所有这样的窗口，并改动成一样的柔顺滑动。”

- 不只是整张页面要顺。
- 股票列表、弹出的内容区和类似内部滚动窗口，也要有一致的手感。
- 不能出现主页面很顺，鼠标一进入列表就突然变硬、变快的割裂感。

### 4. 按钮也要有反馈

你最初明确把按钮列为需要动画的对象。

**归纳原则**

悬停、按下、选中、切换等状态应有轻量反馈；反馈服务于“我正在操作什么”，而不是让所有按钮不停晃动。

### 5. 明确不接受的方向

- 为了“有动画”而加动画。
- 普通滚动效果替代你想要的角色出场。
- 过度果冻化和夸张形变。
- 多个区域采用不同的滚动手感。
- 动作很炫，但延迟用户查看内容或执行操作。

## 七、登录页：简洁、居中、半枚金币

### 1. 构图要求

**明确要求**

- 参考提供的 MetaMask 登录截图，简化页面。
- 登录表单居中，保持明确、集中的视觉焦点。
- 使用时序自己的品牌标识。
- 金币从页面下方升起，停下后只显示半个。
- 金币中间的图案为 **美元符号 $**。

**归纳原则**

登录页应像一个完整、简洁的入口场景，不要加回营销说明、重复导航、演示按钮或大量辅助卡片。

### 2. 小状态也必须精致

- 登录按钮、输入框、密码错误、访客入口、已登录状态，统一字体和视觉风格。
- 不要只有 Logo 和金币有设计感，其余文字像默认网页。
- 报错要清楚，但不能与整个页面的色彩和字重脱节。

### 3. 登录后的落点

**最新明确要求**

> “登录之后界面要进入顶端。”

登录成功后从目标页面顶部开始，不要直接跳到筛选结果或其他中间区域。

## 八、与美观直接相关的使用体验

这些要求不只是视觉，但决定网站是否显得完整、顺手。

### 1. 在当前上下文里完成操作

- 公司板块的基金列表里，应能直接选择基金进行对比。
- 不要逼用户离开当前列表，再重新搜索相同对象。
- 持仓区域也要能看到趋势，不只是孤立的数字。

### 2. 信息位置服从问题的重要程度

- A/C 份额差异放到对比界面最上面。
- 解释不能停留在“长期 A、短期 C”这种模糊概念；用户希望具体理解持有时间与费用的关系。
- 美股公司对用户较陌生，候选股票需要公司介绍。
- 数据卡片和比较结果应帮助理解差异，不能只把大量数字摆出来。

### 3. 重要功能不要埋得太深

- 股票与基金研究入口要容易找到。
- 市场概览要能在进入首页时尽早看到。
- 持仓分析是优先级很高的任务入口。
- 研究工具既要易用，也不能破坏页面的主次关系。

### 4. 彩蛋应当小而完整

你把“用户自带 API Key 的持仓模型分析”入口定位为一个小彩蛋。

**归纳原则**

这类提示可以有趣，但应克制，不应变成占满首页的大块宣传或阻断正常研究流程的复杂步骤。

## 十、以后修改时的验收清单

### 视觉

- [ ] 是否仍然是「时序 SHIXU」自己的视觉语言？
- [ ] 中文与英文的字体层级、间距是否协调？
- [ ] 登录提示、错误状态等边角是否同样精致？
- [ ] 金币是否仍是纯色色块，而非写实金属？
- [ ] 首页金币是否居中、大小合适、上下留白平衡？
- [ ] 陪衬是否足够轻，没有抢走主体和研究内容的注意力？
- [ ] 导航岛是否足够舒展，内部内容是否随之合理分布？
- [ ] 同一级卡片是否保持一致，视觉强调是否有明确含义？
- [ ] 是否又出现了大量装饰箭头或被删除的文案？

### 动态

- [ ] 市场切换时，是否先轻转金币，再出现新图案？
- [ ] 登录金币是否从下方升起，最终只露半个？
- [ ] 滚动是否柔顺、容易控制，没有过度弹跳或漂移？
- [ ] 主页面与内部列表的滚动手感是否一致？
- [ ] 按钮反馈是否轻量、清楚、统一？
- [ ] 动效是否影响阅读或让用户等待？

### 布局与流程

- [ ] 基金是否位于四个市场的最后？
- [ ] 市场按钮是否没有跟着顶部导航吸顶？
- [ ] 首页是否能尽早看到六个主要指数？
- [ ] 重要研究入口是否容易找到？
- [ ] 登录后是否落到页面顶部？
- [ ] 当前列表里的对象能否顺手加入对比？

## 十一、可直接交给下一位设计师或开发者的简版要求

> 为「时序 SHIXU」延续一套有 Web3 个性、简洁且有质感的视觉与交互。品牌标语为「度时间，探秩序。 / Measure Time. Explore Order.」。采用横向舒展的顶部悬浮导航岛，主导航吸顶，市场按钮不吸顶，研究工具放侧边，避免重复装饰箭头。
>
> 首页金币居中、尺寸克制、上下留白平衡，可有少量陪衬。金币用纯色色块和立体切面表现厚度，不要写实金属感。A 股为浦东建筑群、美股为卡通自由女神像、港股为维多利亚港、基金为北京中轴线；切换市场时金币轻转后露出新图案。正式版不要重播按钮、金币下方说明，也不要恢复“今天，进入哪个市场？”及其副标题。
>
> 登录页保持简洁居中，底部美元符号金币自行升起并只露半个。品牌、表单、提示、报错、访客入口统一字体风格。滚动以柔顺可控为准，主页面与所有内部列表一致，避免过度果冻化。登录后进入页面顶部。
>
> 重要研究内容优先，首页尽早展示主要指数，市场顺序为 A 股、美股、港股、基金。质感来自比例、排版、一致性和自然的反馈，不靠堆装饰或堆动画。
